# TX-5DR 1.0.1

本次正式版更新重点是依赖安全、日志本性能、电台连接稳定性和更新可靠性。

## 安全与依赖

- 更新服务器认证、HTTP、WebSocket、上传解析、证书和归档依赖，以及 Electron、随包 Node.js 和桌面更新组件。
- 迁移至 Zod 4，保留旧配置默认值和局部设置更新行为，避免更新单个选项时覆盖其他配置。
- 发布前 npm 审计未发现 Critical 或 High 级公告；构建工具链仍有 minimatch 中危和 deepmerge 低危公告，不代表所有依赖漏洞已清零。

## 电台与音频

- 改善 ICOM WLAN 会话生命周期，加入 MK2 支持并隔离 CW 确认超时，降低异常响应对后续控制的影响。
- 修正 FT-DX10 频率与模式更新的 VFO 一致性，改善相同型号 USB 音频设备的识别。
- 语音模式支持软件静噪；模式写入失败时保留操作入口并提示。支持无 CAT 的 PTT 使用场景。
- 完善 Linux 桌面 GTK 兼容处理。

## 日志本与插件

- 改善大批量日志导入与 ADIF 导出的响应，减少后台文件处理对界面的影响。
- 插件自动禁用时提供管理员可见的错误原因和诊断详情。
- 更新插件开发与测试工具；第三方插件仍需确认各自的数据和 Host 兼容性。npm SDK 独立发布。

## 更新与分发

- 修复 Windows 更新备份受 Chromium 锁定文件影响的问题，同时保留电台与插件数据的持久化收尾。
- 改善旧 nightly 安装记录的识别，更新提示只对目标频道的未读版本显示。
- 改善 Docker 构建和运行镜像分层；Linux AppImage 的更新元数据从包内 blockmap 导出，保持安装包字节不变。

本版本通过自动化回归、原生协议与编解码测试，以及 FT8 主叫、FT8 应答、FT4 主叫和静默对端的完整虚拟电台场景。虚拟场景不代替具体实体电台或射频环境验证。

安装前停止发射并备份数据。选择“正式版”频道后检查更新；跨频道可能需要确认降级。Linux Server 使用网页提供的 CLI 命令，Docker 的 `stable`/`latest` 指向正式版，Android Runtime 通过原生状态页更新。Android APK 和 npm SDK 不随本次 Host 发布更新。安装方式与平台要求见 https://tx5dr.com/guide/maintenance 。
