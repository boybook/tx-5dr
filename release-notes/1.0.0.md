# TX-5DR 1.0.0

TX-5DR 的首个正式版，提供浏览器操作的数字模式、语音电台和日志本，以及桌面、Linux Server、Docker 和 Android Runtime 分发。

## 更新频道

在更新页选择“正式版”或“Nightly”。切换只检查目标，不会立即安装。旧 nightly 用户请先安装支持频道选择的过渡 nightly，再切到正式版；不支持自动安装的包可以从官网覆盖安装。用户数据目录保持不变。

Linux Server 在网页选择频道后，在服务器执行提供的命令。Android 在原生状态页更新运行时，APK 独立升级。Docker 的 latest/stable 指向正式版；需要继续开发版请改用 nightly。

## 安装与恢复

下载安装包前核对操作系统、架构及桌面/服务器类型。跨频道可能回退到较低版本，旧版本和第三方插件不保证能读取较新的数据。安装前停止发射并备份；恢复旧快照会丢失备份之后的变化。

Windows 便携包、Linux 桌面 DEB/RPM/ZIP 使用手动安装；NSIS、macOS 和 AppImage 提供应用内安装。Android 需要 64 位 arm64 Android 9 或更高版本。平台支持与操作步骤见 https://tx5dr.com/guide/maintenance 。
