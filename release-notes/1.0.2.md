# TX-5DR 1.0.2

本次正式版完整重做了日志本 3D 地球，新增 RTTY 键盘模式和桌面端远程电台连接，并加强 Hamlib 电台的无人值守恢复和 FT8 时序准确性。

## 日志本 3D 地球重做

日志本地球从逐个对象绘制改为 GPU 着色器图层整体重做，在此基础上增加了以下能力：

- **画面**：地形起伏（Natural Earth 晕渲地形，显卡支持时使用 8K 贴图）、昼夜明暗与晨昏线、夜侧城市灯光和地平线大气；任意缩放下陆地不再闪烁。
- **3D / 平面地图切换**：一键在 3D 地球和平面地图之间平滑展开，所有图层同步切换；平面地图缩小时左右循环显示；两种视图都支持触控板平移和双指缩放。
- **网格图层**：按 Maidenhead 大区和方格逐像素着色，区分已通联与已确认的网格，并跟随日志本表格的波段和模式筛选。
- **实时电台**：显示最近接收时隙听到的电台并按优先级分层，需要的 CQ 电台带标签。单击固定电台卡片，有操作员管理权限时双击直接呼叫，日志本页面无需切回主界面。
- **接收反馈（PSK Reporter）**：显示哪些电台收到了本操作员的信号，包括接收点、覆盖光雾、新接收站的提示光环和“对方也听到你”的 QSO 目标标记，提供四种配色；亮度按发射时间计算，批量迟到的报告仍对应本次发射。默认关闭，需管理员在设置中开启。
- **弧线与标记**：进行中的 QSO 弧线从地球上显示的本站位置出发；日志刷新、同步或操作员状态变化时，已有的弧线和光环保持不动，不再闪烁或重复脉冲。
- **性能**：转动和缩放时不重建模型、不重新渲染页面；渲染分辨率随帧率自动调整，地球移出屏幕时暂停动画；实时数据只刷新地球本身。

## 新增功能

- RTTY 键盘模式：AFSK 发射，支持可撤回的预输入、重复 CQ、宏和 QSO 日志卡；接收端提供实时解码、按新调谐重解最近 60 秒、锁定与 SNR 显示，以及全通带信号浏览。发送端客户端断开时立即停止发射。
- 桌面端可连接局域网或互联网上的其他 TX-5DR 电台，每个电台独立窗口、独立登录会话；自签名证书需核对 SHA-256 指纹后信任，证书变化时阻止连接。可在“电台连接”中管理，或从局域网发现的电台列表中添加。
- TCI 电台若支持 TUNE，手动调谐改为使用电台自身的 TUNE 功能，载波和功率由电台调谐设置决定；不支持的电台仍使用音频单音。
- 浏览器中可将频谱在单独的标签页打开，登录状态在同源标签页之间同步。

## 电台与稳定性

- Hamlib 默认在独立进程中运行。电台控制库卡死或崩溃后会自动重建会话并恢复运行中的自动化，掉线后在快速重试之后每 60 秒继续重连，直到电台恢复或手动停止。如遇兼容问题，可在电台设置中将“Hamlib 运行模式”改为“进程内运行”。
- FT8 的发射混音、迟到判断和换频后的过期解码统一使用 NTP 校准时钟，校准偏移不为零时不再错位；发射中途取消的接收时隙会保存已经解出的结果。
- 音频流卡顿或长时间丢包后，不再把断点前的音频错位到新时间轴上，避免跨断点的 FT8 解码读到错位音频。
- 修复电脑负载较高或解码较慢时，自动通联在已发送 73 后再次重复发送 73 的问题。
- 修复时隙边界处理被延迟时，已过时的发射内容未被纠正，导致对方回复 73 后仍多发一次 RR73、重复发送上一步报告，或日志中的发出报告与实际发射不一致的问题。
- 未设置信号报告时，发送实测的对方 SNR，不再发送 +00。
- 修正 Fox/Hound 模式下信号报告的方向。
- 开启“停止时自动回复直呼”后，在较晚解码窗口才解出的直呼也能唤醒操作员。
- 激活 Profile 时引擎按该 Profile 记住的模式启动，不再与电台模式不一致。

## 界面与性能

- 修复浏览器长时间运行后内存持续增长（可达 GB 级）的问题，并减少频谱数据推送引起的界面重复渲染。
- 插件市场和设置对话框改为紧凑布局，对话框尺寸跟随窗口。
- macOS 桌面端在页面缩放时，台站信息不再遮挡窗口按钮。
- 补齐日文界面缺失的文本。

## 插件

- 插件市场改为按 Plugin API 版本选择插件版本：自动安装与当前 TX-5DR 兼容的最新版本，也可固定安装某个版本（包括较旧的兼容版本）。不兼容的插件单独列出并说明原因。
- 面向上一个 Plugin API 大版本的插件仍可加载，并标注为旧版；无法加载的插件显示在“已安装”中并给出原因，不再直接消失。
- Plugin SDK 已独立发布 2.7.0 和 2.8.0（新增 RTTY 模拟模式）。`@tx5dr/core` 移除了未被使用的 `CycleManager`、`ClockSourceMock`、`validateDXCCWithHamQTH` 和 13 个 API 客户端方法，直接依赖这些接口的插件需要调整。

## 桌面端、日志与分发

- 修复桌面端快捷键和 Voice PTT 订阅泄漏导致命令重复触发的问题，移除启动日志中误导性的错误。Electron 升级至 45.3.2。
- 服务端日志文件保留错误的消息和堆栈，便于排查问题。
- 更新构建工具链；nightly 改为每日定时发布。

## 网络与隐私

- 远程访问预设为“局域网”时，已安装的服务端和桌面端会通过 DNS-SD（`_tx5dr._tcp`）在局域网中广播，供桌面端发现。广播内容不含呼号、用户或主机名；公网预设、Docker、Android 默认不广播，设置环境变量 `TX5DR_DISCOVERY=0` 可关闭。
- 新增公开接口 `GET /api/station/identity`，只返回电台实例 ID 和版本等公开身份信息。
- PSK Reporter 接收反馈开启后，只在日志本页面打开时将操作员呼号发送至 mqtt.pskreporter.info 和 retrieve.pskreporter.info。

本版本通过自动化回归、Hamlib 进程隔离与解码集成测试，以及 FT8 主叫、FT8 应答、FT4 主叫、静默对端和 RTTY 主叫、应答、噪声、发送端断开的完整虚拟电台场景。Hamlib 故障恢复另在 IC-705（最小功率接假负载）上验证。虚拟场景不代替具体实体电台或射频环境验证。

安装前停止发射并备份数据。选择“正式版”频道后检查更新；跨频道可能需要确认降级。Linux Server 使用网页提供的 CLI 命令，Docker 的 `stable`/`latest` 指向正式版，Android Runtime 通过原生状态页更新。Android APK 不随本次 Host 发布更新。安装方式与平台要求见 https://tx5dr.com/guide/maintenance 。
